# Demo audio files

These short, original 8-second WAV sketches are generated locally for the frontend demo. They are mono, 22.05 kHz, 16-bit PCM and can be previewed in the studio or downloaded from Storage.

- `warm-drum-loop.wav` — a simple kick, snare, and hi-hat loop.
- `kyoto-piano-sketch.wav` — a soft plucked piano-like melody.
- `deep-bass-loop.wav` — a low synthesized bass phrase.

They are mock assets and are not AI-generated recordings.
